Terminal Mac - cara memasang sebagai aplikasi

1. Letakkan semua file ini di satu folder di server HTTPS (misalnya GitHub Pages, Netlify, atau Vercel).
   Fitur "pasang aplikasi" dan cache offline hanya berjalan lewat HTTPS atau localhost.
2. Buka alamat situsnya di Chrome atau Edge di Mac, lalu klik ikon Pasang di address bar
   (atau menu > "Pasang Terminal Mac"). Aplikasi akan muncul di Dock/Launchpad.
3. Di Safari (macOS Sonoma ke atas): File > Add to Dock.
4. Di HP: buka di Chrome/Safari, lalu pilih "Tambahkan ke Layar Utama".

Untuk membuka tanpa server, cukup klik dua kali index.html (tanpa pasang aplikasi).
